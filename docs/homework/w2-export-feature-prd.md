# 数据导出功能 PRD

## 1. 产品概述

### 1.1 背景
当前数据库查询工具支持执行 SQL 查询并在 Web 界面展示结果，但用户无法将查询结果导出到本地进行进一步分析或分享。

### 1.2 目标
为数据库查询工具添加数据导出功能，支持将查询结果导出为 CSV 和 JSON 格式，提升用户数据处理效率。

### 1.3 目标用户
- 数据分析师：需要将查询结果导入 Excel 或其他分析工具
- 开发人员：需要导出数据用于测试或数据迁移
- 业务人员：需要分享查询结果给团队成员

## 2. 功能需求

### 2.1 核心功能

#### F1: 导出查询结果
**优先级**: P0

**功能描述**:
- 用户执行查询后，可以将结果导出为文件
- 导出基于**当前页面已展示的查询结果快照**，不重新执行 SQL
- 支持两种格式：CSV、JSON
- 文件自动命名：`{database_name}_query_{timestamp}.{csv|json}`

**交互流程**:
1. 用户执行 SQL 查询
2. 查询结果展示在表格中
3. 用户点击"导出"按钮，选择格式
4. 浏览器自动下载文件

**验收标准**:
- CSV 文件可被 Excel 正常打开
- JSON 文件格式正确，可被解析
- 文件名包含数据库名和时间戳
- 支持导出空结果：当 `rowCount = 0` 时生成 **0 字节文件**

#### F2: 一键执行并导出
**优先级**: P1

**功能描述**:
- 提供"执行并导出"按钮，一次点击完成查询和导出
- 用户选择导出格式后，自动执行查询并下载文件

**交互流程**:
1. 用户在 SQL 编辑器输入查询
2. 点击"执行并导出"按钮
3. 选择导出格式（CSV/JSON）
4. 系统执行查询并自动下载文件

**验收标准**:
- 查询失败时，不生成文件，显示错误信息
- 查询成功后，先展示查询结果，再触发文件下载
- 查询结果与导出内容保持一致（同一快照）

#### F3: 智能导出提示
**优先级**: P2

**功能描述**:
- 查询成功后，自动弹出提示询问是否导出
- 提供快捷操作按钮

**交互流程**:
1. 用户执行查询成功
2. 系统弹出提示："查询成功！共 X 条记录，是否导出？"
3. 提供三个选项：[导出为 CSV] [导出为 JSON] [关闭]
4. 用户选择后自动下载或关闭提示

**验收标准**:
- 仅在查询成功且有结果时提示
- 用户可以关闭提示（不强制导出）
- 点击“关闭”仅关闭提示，不触发任何导出请求
- 提示不影响查询结果的正常展示

### 2.2 非功能需求

#### NF1: 性能
- 导出 10,000 行数据应在 3 秒内完成
- 支持导出最多 100,000 行数据
- 大数据集导出时显示进度提示

#### NF2: 兼容性
- 支持 Chrome、Firefox、Safari、Edge 最新版本
- CSV 文件兼容 Excel、Google Sheets
- JSON 文件符合标准格式

#### NF3: 安全性
- 导出操作需要数据库连接权限验证
- 不在服务器保存导出文件
- 敏感数据导出时记录审计日志

## 3. 用户故事

### US1: 数据分析师导出数据
**作为** 数据分析师
**我想要** 将查询结果导出为 CSV
**以便于** 在 Excel 中进行数据透视分析

**场景**:
1. 执行销售数据查询：`SELECT * FROM sales WHERE date >= '2024-01-01'`
2. 查看结果确认无误
3. 点击"导出为 CSV"
4. 在 Excel 中打开文件进行分析

### US2: 开发人员快速导出测试数据
**作为** 开发人员
**我想要** 一键执行查询并导出 JSON
**以便于** 快速获取测试数据

**场景**:
1. 输入查询：`SELECT * FROM users LIMIT 100`
2. 点击"执行并导出为 JSON"
3. 直接获得 JSON 文件用于测试

### US3: 业务人员分享查询结果
**作为** 业务人员
**我想要** 导出查询结果并分享给团队
**以便于** 团队成员查看数据

**场景**:
1. 执行月度报表查询
2. 查询成功后，系统提示"是否导出？"
3. 选择"导出为 CSV"
4. 通过邮件分享文件给团队

## 4. 技术约束

### 4.1 后端
- 使用 FastAPI 框架
- 导出格式：CSV 使用 Python `csv` 模块，JSON 使用标准库
- 响应类型：`StreamingResponse` 避免内存溢出

### 4.2 前端
- 使用 React + TypeScript
- UI 组件：Ant Design
- 文件下载：使用 Blob API

### 4.3 数据格式

**CSV 格式**:
```csv
id,name,email,created_at
1,John Doe,john@example.com,2024-01-01 10:00:00
2,Jane Smith,jane@example.com,2024-01-02 11:30:00
```

**JSON 格式**:
```json
{
  "columns": ["id", "name", "email", "created_at"],
  "rows": [
    {"id": 1, "name": "John Doe", "email": "john@example.com", "created_at": "2024-01-01 10:00:00"},
    {"id": 2, "name": "Jane Smith", "email": "jane@example.com", "created_at": "2024-01-02 11:30:00"}
  ],
  "rowCount": 2,
  "exportedAt": "2024-01-15T10:30:00Z"
}
```

## 6. 成功指标

- 导出功能使用率 > 30%（查询次数中导出的比例）
- 导出成功率 > 99%
- 用户反馈满意度 > 4.5/5
- 导出操作平均耗时 < 2 秒

## 7. 风险与依赖

### 风险
- 大数据集导出可能导致浏览器内存不足
- CSV 格式可能存在特殊字符转义问题
- 不同浏览器的文件下载行为差异

### 缓解措施
- 限制单次导出最大行数
- 使用标准 CSV 转义规则
- 充分测试主流浏览器

### 依赖
- 无外部依赖
- 需要现有查询功能正常工作

## 8. 未来扩展

- 支持 Excel (.xlsx) 格式导出
- 支持 SQL 文件导出（包含 INSERT 语句）
- 支持自定义导出字段
- 支持导出模板保存
- 支持定时导出任务
